# Better Meeting image generation

Mode: built-in `image_gen` tool.

## Application icon

> Use case: logo-brand
>
> Asset type: 1024 x 1024 macOS application icon master for a native meeting recorder named Better Meeting
>
> Primary request: Create one distinctive abstract “captured voice” symbol: a compact transcript-page shape with a subtle folded corner whose negative space holds a simple three-beat audio pulse, plus one small coral recording dot. The page and pulse must read as one unified mark, not separate clip-art objects.
>
> Style/medium: polished vector-friendly macOS app icon with restrained tactile depth, crisp geometry, and a strong silhouette that remains recognizable at 16 px
>
> Composition/framing: centered rounded-square macOS icon, generous optical safe margin, balanced negative space, front-facing, no perspective mockup
>
> Color palette: deep graphite blue-black outer tile, warm ivory mark, one signal-coral red recording dot; restrained highlights only
>
> Materials/textures: subtly soft enamel or finely finished anodized material, nearly flat
>
> Constraints: transparent canvas outside the rounded-square icon; no text; no letters; no Markdown characters; no microphone; no headphones; no people; no checkmark; no calendar; no watermark; no busy waveform; no rainbow gradient; no external scene or device mockup

>
> Constraints: genuine transparent background; no rounded-square app tile; no gray; no color; no shading; no shadow; no text; no microphone; no headphones; no people; no extra border; no watermark; preserve a bold simple silhouette rather than fine detail
